《台灣步行挑戰賽》規格書

一款用黑色幽默呈現台灣人行環境困境的互動網頁小遊戲。

交付物：單一 index.html（CSS、JavaScript 皆內嵌），發佈於 GitHub Pages。

1. 作品目標

  • 核心訊息：台灣的人行環境對輪椅使用者、推嬰兒車的家長、長者來說「根本走不了」，連年輕人也不安全。這不是使用者的問題，而是道路設計的問題。
  • 表達手法：玩家實際「走一段台灣的路」，遊戲刻意設計成無法通關；接著用同一角色走日本、荷蘭的同一段路，輕鬆通關，用反差說話。
  • 語氣：諷刺、黑色幽默，用官腔口吻包裝荒謬。真實數據只在結尾輕輕帶出，不說教。
  • 目標體驗時間：約 5 分鐘（一輪約 3 分鐘，多數玩家會換角色再玩一次；成就系統鼓勵重玩）。
  • 操作裝置：電腦（鍵盤 + 滑鼠）。

4. 遊戲機制（S3 / S5 共用）

4.1 畫面與操作

  • 斜上方 3/4 立體視角的橫向捲軸（像素風），畫布 960 × 540（依視窗等比縮放）。鏡頭從左前上方看街道，所有物體都有頂面、前面和側面（走過去會撞上的那一面），並且有地面陰影，讓高低差和路上的東西一眼看得出來。
  • 畫面分成兩條「道」：
    • 上道：騎樓／人行道（行人該走的地方）
    • 下道：靠人行道的車道。台灣、荷蘭靠右行駛，車流迎面而來；日本靠左行駛，車流從背後來
    • 畫面最下方另有一條對向車道（背景車流，不會撞到玩家）
  • 操作：← → 移動、↑ ↓ 切換上道／下道、空白鍵 動作（抬車、抬腳、跳）、C 打 1999 陳情、Esc（或 P）暫停、M 靜音。
  • 畫面上方 HUD：關卡名稱、體力條、危險值條、已用時間；嬰兒車角色多一條寶寶哭鬧值；右上角有「⏸ 選單」按鈕。
  • 暫停／離開：遊戲中按 Esc 或 P、點「⏸ 選單」，或切到別的視窗／分頁時，遊戲會暫停並顯示選單：繼續走、重新走這一關、換個角色（回 S2）、離開，回到首頁（回 S1）。暫停時時間完全停止。

4.2 數值規則

  • 危險值（0～100）：待在車道時每秒 +2.5；車輛擦身而過 +5；被莽撞的車撞上 +30（撞上前頭上會閃紅色「!!」）；被倒車機車撞 +20；達到 100 → 陣亡。每進入下一段，危險值減半（「台灣限定優惠」），讓玩家有機會看完三段路。
  • 體力（0～100）：抬車、抬腳、爬路緣時消耗，每秒回復 6 點。體力不足時無法通過台階，只能走車道。
  • 從車道爬回上道：輪椅只能在「沒被機車擋住的斜坡」爬上去；嬰兒車、長者在沒被佔住的斜坡免體力，其他地方爬路緣每次消耗 15 體力；年輕人不受限。被機車佔住的斜坡，所有角色都不能從那裡上下（會顯示「斜坡上停了一台機車」）。日本、荷蘭沒有這個限制。
  • 水溝蓋（只在台灣）：人行道上共有 6 個鐵格柵水溝蓋。走到水溝蓋前按 空白鍵 可以跨過去（年輕人跳過，免費；嬰兒車、長者消耗 10 體力；輪椅無法跳，只能改走車道）。沒跨過去就會卡住，無法移動，必須連按 ← → 掙脫（輪椅 8 下、嬰兒車 6 下、長者 5 下、年輕人 3 下）。卡住期間每 2.4 秒會有機車在後面按喇叭（寶寶哭鬧值上升）。是否冒險走人行道，由玩家決定。
  • 1999 陳情：按 C 打電話陳情，會收到一句官腔回覆（每 5 秒一次），什麼都不會改變，但站著等回覆可以順便休息（體力 +10）。日本、荷蘭關卡打電話會得到「沒有什麼需要陳情的」。
  • 隨機路況事件（每次開局重新抽籤）：台灣關卡有 7 個固定「事件欄位」，每次開局隨機決定各欄位發生什麼事（或什麼都沒有），所以每一輪的路都不一樣：
    • 停車場出入口：牆上有鐵捲門與警示燈。走近時警示燈閃爍並發出嗶聲，約 1.5 秒後車子衝出來穿過人行道開到車道上。車子出來時站在它的路徑上會被撞（+30 危險值）。玩家要決定：等它先走，還是搶在它出來之前衝過去。
    • 網紅擋路：網紅站在人行道正中間拍照打卡，所有角色都過不去。對他按 空白鍵 喊「借過」，連喊 3 次他才會讓開。
    • 施工圍籬：圍籬橫跨整條人行道，所有角色（包含年輕人）都只能下車道。每輪最多 2 個。
  • 路人：街上有路人，玩家靠近時說一句話（台灣：「你為什麼不搭計程車？」「我們有在規劃，已經規劃十年了。」等；日本、荷蘭：「需要幫忙嗎？」「慢慢來，我們等你。」），不會擋路。
  • 「根本過不去」設計：每段路至少有一個障礙，對所選角色來說無論怎麼操作都過不去，玩家只能下到車道。第 3 段路口為必死劇本（見下文），保證所有角色都無法通關。

4.3 三段台灣路況

4.5 移民模式（S5）

  • 玩家選擇 🇯🇵 日本 或 🇳🇱 荷蘭，使用同一角色，走相同長度的三段路，自己操作。
  • 沒有任何過不去的障礙，約 30～40 秒可抵達終點（長者約 70 秒）。車輛會停下來等行人，不會增加危險值。畫面上方固定顯示：「⚠️ 本關卡過於簡單，不適合台灣玩家」。

6. 視覺與音效

  • 視覺：像素風 + 斜上方立體視角（見 §4.1）。所有圖像用 Canvas 程式繪製，不引用外部圖檔。介面文字使用系統中文字體；畫布設定 image-rendering: pixelated。
  • 讓高低差看得見的手法：
    • 每家店的地板高度不同，地板會真的墊高，交界處露出側面，並畫黃黑警示條；下台階處地板上有陰影。
    • 台階前方浮出高度標示（例如「↑ 18 cm」「↓ 24 cm」），走近才顯示。
    • 路緣有明顯的立面。
    • 斜坡：路緣切出一塊亮黃色的斜面，伸進車道，邊緣有黃色線、斜面上畫藍色向上箭頭，旁邊立藍色輪椅標誌；走近時上方浮出「♿ 斜坡」標籤（被機車佔住的顯示紅色「斜坡（被機車占用）」並看得到機車停在斜面上）。輪椅走在車道上時，可用的斜坡下方會閃黃色箭頭。
    • 為了看得清楚，高度刻意誇張（1 單位約 3 公分，角色比例不變）。
  • 讓「路上有東西」看得見的手法：停滿機車的騎樓排成好幾列、騎樓有樓板和柱子（角色走過會被柱子擋住）、電線桿旁加上垃圾桶與腳踏車、窄人行道旁堆滿貨架與花台；所有物體都有陰影。
  • 標線型人行道的畫法（參考臺中市〈標線型人行道繪製指引〉、新聞與網路上的實景照片）：
    • 顏色為青綠色（偏藍的綠，不是草綠），油漆有些斑駁、有路邊排水溝蓋。
    • 緊貼騎樓或店面的鐵捲門，沒有路緣石；外側是一條白實線，白線外再一條紅線（禁止臨時停車）。
    • 路面上以白色漆標出「人行道」三個字與「大人牽小孩」的行人圖示，每隔一段重複。
    • 路口的斑馬線是綠白相間。
    • 車子、機車壓在白線上停放（實景常見），行人只好走到旁邊的車道。
    • 這種人行道依規定只能設在巷道、集散道路等服務性道路；本作品為了諷刺效果，把它放在路口前。
  • 文字清晰：畫面中的文字（高度標示、斜坡與水溝蓋標籤、路人對話泡泡）不畫在低解析度的像素畫布上，而是畫在另一層以螢幕實際解析度繪製的透明畫布，字體清楚不糊。
  • 配色：台灣關卡用灰暗、雜亂的色調（招牌紅黃綠混雜）；日本、荷蘭關卡用乾淨明亮的色調，強化反差。
  • 音效：除寶寶哭聲外，全部用 Web Audio API 即時合成。寶寶哭聲合成出來不像人聲，因此改用真實錄音：從公眾領域錄音裁出約 1.4 秒、壓成單聲道 MP3（約 8 KB），以 base64 文字直接嵌在 index.html 內，不引用外部檔案。若瀏覽器解碼失敗，退回合成版。

  • 音量控制：所有音效的最大音量大致相同（撞擊聲不會比喇叭大聲很多），總輸出另加限幅器，多個音效疊在一起也不會突然爆音。

7. 技術規格

  • 單一檔案 index.html：CSS 寫在 <style>、JavaScript 寫在 <script>，不依賴任何外部資源，離線也能開啟。
  • 使用 <canvas> + requestAnimationFrame 實作遊戲迴圈；以狀態機管理 S1～S7 畫面切換。
  • 音效需在玩家第一次點擊後才啟動（符合瀏覽器自動播放限制）。
  • 支援 Chrome、Edge、Safari、Firefox 最新版；最低解析度 1280 × 720。
  • 發佈：上傳至 GitHub repository，開啟 GitHub Pages，網址根目錄即為遊戲。
